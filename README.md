# SignalPaper HOON

Android demo application for HOON's paper-trading portfolio.

## Demo holdings

- NVIDIA (NVDA): 162 shares at $41 average
- Apple (AAPL): 14 shares at $382 average
- Tesla (TSLA): 170 shares at $61 average
- DiDi Global (DIDIY): 511 shares at $14 average
- Luckin Coffee (LKNCY): 68 shares at $2.53 average

The app uses a fixed July 17, 2026 market snapshot and includes an offline portfolio dashboard, company logos, news intelligence, position details, and simulated buy/sell orders.

GitHub Actions builds a downloadable debug APK.
